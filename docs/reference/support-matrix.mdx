---
title: "Supported Products"
---
cuDNN Frontend 1.28.0 is supported by cuDNN backend versions starting with v8.5.0.

The GPU, CUDA Toolkit, CUDA driver, CPU architecture, and OS requirements are the same as for the cuDNN backend version with which you are using cuDNN frontend. For details, refer to the support matrix for the relevant cuDNN backend version:

- [cuDNN backend support matrix](https://docs.nvidia.com/deeplearning/cudnn/backend/latest/reference/support-matrix.html)

  Earlier 9.x releases are available from the version selector in the cuDNN backend documentation.
- [v8.x archives](https://docs.nvidia.com/deeplearning/cudnn/archives/)
