The NVIDIA CUDA Deep Neural Network library (cuDNN) provides optimized operations for training and inference on NVIDIA GPUs. Use attention, matrix multiplication, convolution, and multi-operation fusion through your framework or the cuDNN Python and C++ APIs.

## Integrations

Use cuDNN through the tools in your AI stack, or build directly on its graph APIs. These paths show how selected frameworks and libraries reach cuDNN. Support depends on the operation, selected backend, library versions, and GPU.

## Get started

Set up a compatible NVIDIA GPU, CUDA, and cuDNN backend before using the frontend. Check the [supported products](/reference/support-matrix) and [installation guide](/installation/frontend) for your environment.

<Tabs>
  <Tab title="Python">
    Install the Python frontend:

    ```bash
    pip install nvidia-cudnn-frontend
    ```

    Check that Python can load the cuDNN backend:

    ```python
    import cudnn

    print(cudnn.backend_version())
    ```

    Follow the [Python installation guide](/installation/frontend/python-frontend-install), then [build and execute your first graph](/quickstart).

  </Tab>
  <Tab title="C++">
    Set up the headers and libraries with the [C++ installation guide](/installation/frontend/cpp-frontend-install). Include the frontend and create an empty graph:

    ```cpp
    #include <cudnn_frontend.h>

    auto graph = cudnn_frontend::graph::Graph();
    ```

    Follow the [quick start](/quickstart) for a complete example that defines tensors, adds an operation, builds an execution plan, and runs the graph.

  </Tab>
</Tabs>

For most applications, start with the frontend APIs. Use the [cuDNN backend API](https://docs.nvidia.com/deeplearning/cudnn/backend/latest/api/overview.html#api-overview) if you need a C-only interface or legacy fixed-function routines that the frontend does not expose.

  function selectPath(event) {
    if (!(event.target instanceof Element)) return;
    const control = event.target.closest(
      "button[data-cudnn-filter], button[data-cudnn-route]",
    );
    if (!control) return;
    const root = event.currentTarget;
    const filter = control.dataset.cudnnFilter || "all";
    const route = control.dataset.cudnnRoute;
    const selected =
      route && control.getAttribute("aria-pressed") !== "true" ? route : null;
    const active = selected ? related[selected] || [selected] : [];

    root.querySelectorAll("[data-cudnn-filter]").forEach((button) => {
      button.setAttribute(
        "aria-pressed",
        String(button.dataset.cudnnFilter === filter),
      );
    });
    root.querySelectorAll("[data-cudnn-route]").forEach((button) => {
      button.setAttribute(
        "aria-pressed",
        String(button.dataset.cudnnRoute === selected),
      );
      button.toggleAttribute(
        "data-cudnn-active",
        active.includes(button.dataset.cudnnRoute),
      );
    });
    root.querySelectorAll("[data-cudnn-lane]").forEach((lane) => {
      lane.classList.toggle(
        "cudnn-muted-lane",
        filter !== "all" && lane.dataset.cudnnLane !== filter,
      );
      lane.toggleAttribute(
        "data-cudnn-highlight",
        lane.dataset.cudnnLane === filter ||
          Boolean(lane.querySelector("[data-cudnn-active]")),
      );
    });
    root.querySelectorAll("[data-cudnn-detail]").forEach((panel) => {
      panel.hidden = panel.dataset.cudnnDetail !== (selected || filter);
    });
  }
