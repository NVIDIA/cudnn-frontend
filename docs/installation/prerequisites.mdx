These prerequisites apply to both Linux and Windows platforms.

## Required Software and Hardware

For the latest compatible versions of required software and hardware such as the OS, NVIDIA CUDA, the CUDA driver, and the NVIDIA hardware, refer to the [cuDNN Support Matrix](/reference/support-matrix).

## Installing NVIDIA Graphics Drivers

Install up-to-date NVIDIA drivers on your system.

1. Go to: [NVIDIA drivers](https://www.nvidia.com/download/index.aspx?lang=en-us).
2. Select the GPU and OS version from the drop-down menus.
3. Download and install the NVIDIA graphics driver as indicated on that web page. For more information, select the **ADDITIONAL INFORMATION** tab for step-by-step instructions for installing a driver.
4. Restart your system to ensure that the graphics driver takes effect.
