12. FlashInfer (flashinfer-ai/flashinfer)
    https://github.com/flashinfer-ai/flashinfer

The batch-invariant GEMMs in python/cudnn/gemm/batch_invariant/ adapt
Apache-2.0 sources from FlashInfer at commit e2d163fb3d46dfe251feba5b6652a08871f4a0b8.
The BF16, FP8, groupwise FP8, MXFP8, NVFP4, MXFP4 and mixed MXFP8 x MXFP4
kernels, K-chunk selection, tile and cluster heuristics, persistent scheduling,
block-scale layouts and ordered FP32 epilogues
come from flashinfer/gemm/batch_invariant/. The CuteF32 arithmetic in
_quantized/arithmetic.py also adapts flashinfer/batch_invariant/fp_interface/cute.py.
The cuDNN Frontend port binds graph tensors and workspace through its own
compiler and launch interface.

The BF16 input generator in test/python/gemm/batch_invariant/test_flashinfer_integration.py
adapts adv_bf16 from tests/gemm/test_batch_invariant_mm_bf16.py at the same
revision. The fixture selects the device to which the generated inputs are copied.

The FP8 split-K projection kernel for decode rows in
python/cudnn/gemm/frost/projection_decode/kernel/fp8_projection_decode_e4m3.py
is derived from FlashInfer's cluster split-K dense GEMM kernel
(flashinfer/gemm/kernels/dense_bf16_gemm_sm100_splitk.py), pinned to
flashinfer-python 0.7.2.post1 (commit beabf5004585b03da60e927bbb803acbaa62fe36).
The derived file retains the upstream notice. The port replaces the BF16/FP16
operands and the optional bias by FP8 E4M3 operands with a scalar FP32 scale and
one BF16 cast, binds static shapes, reserves the shared memory the configuration
uses, allocates the tensor-memory columns the accumulator needs, arms the
cluster reduction barrier at the top of the epilogue role, offers an opt-in
form that holds the tensor memory until the registers read from it are
consumed, and adds the host entry with its typed declines and performance
picks.

The block-scaled FP4 gate / up kernel with a SwiGLU and block-quantising epilogue in
python/cudnn/gemm/frost/swiglu_decode/kernel/swiglu_fp4_decode_nvfp4.py is derived from
FlashInfer's persistent block-scaled dense GEMM kernel
(flashinfer/gemm/kernels/dense_blockscaled_gemm_sm100.py and
dense_blockscaled_gemm_sm100_common.py), pinned to flashinfer-python 0.7.2.post1
(commit beabf5004585b03da60e927bbb803acbaa62fe36). Both files carry NVIDIA's
BSD-3-Clause notice (the text of entry 3); the first states that it was ported from
TensorRT-LLM; the derived file retains that notice. The port replaces the store of the
product by an epilogue that applies SiLU(gate) x up and writes packed FP4 codes with
E4M3 block scales, stages the first weight tiles before the dependent-launch wait, and
adds the host entry with its typed declines.

13. vLLM (vllm-project/vllm)
    https://github.com/vllm-project/vllm

The attention preparation kernel for decode rows in
python/cudnn/attention_prepare/frost/kernel/prepare_decode_f16.py follows the
thread shape and the arithmetic of vLLM's fused QK-RMSNorm + partial RoPE +
gate copy kernel (_fused_qk_rmsnorm_rope_gate_kernel in
vllm/model_executor/layers/fused_qk_norm_rope.py), pinned to commit
2a777ce26e8315fa503ac5e88b595235d1c2b928. vLLM distributes the source file
under Apache License 2.0 (Copyright contributors to the vLLM project); the
derived file names the source and its licence in its header. The port is
written on the CuTe DSL (the source is a Triton kernel), makes the geometry,
the epsilon, the position form, the page size and the integer dtypes
compile-time constants, serves bf16 only (the source takes its input dtype as
a constant), fixes the gain at 1 + weight (the source adds a constant
norm_beta), takes the query rows and the gate rows as two operands with their
own strides (the source reads one [q | gate] row per head), loads a thread's
elements once, reads the rotary partner from another thread of the warp,
writes the keys into a paged pool at a slot and copies the value rows into a
second pool beside them (the source writes the keys to a dense output and has
no value operand) with the store predicated by the pool's capacity, and adds
the host entry with its typed declines and launch arms.

License: Apache License 2.0 (same text as this repository's LICENSE.txt)
